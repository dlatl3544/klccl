마르틴 루터 1483–1546

비텐베르크의 종교개혁자. 1517년 95개조로 면벌부 논쟁을 일으켰고, 라틴어와 독일어로 논고, 설교, 성경 강의, 서신을 남겼습니다. 전집은 바이마르판(WA, 1883–2009)입니다.
